# AcademyBugs - QA & Test Automation Project
## Project Overview
This project demonstrates a structured Software Quality Assurance and Test Automation process using the[ AcademyBugs](https://academybugs.com/) practice application.
The project covers functional testing of the main application modules,preparation of detailed test cases, test execution, defect,identification, and UI automation using Selenium WebDriver with Java and TestNG.
## My Role
### Manual & Automation Tester
* Prepared Test Plan, Test Scenarios, Test Cases, RTM, Bug Report, Test Execution Report, and Test Summary Report.
* Designed and executed manual test cases covering Examples of Bugs, Types of Bugs, Find Bugs, Report Bugs, Help, and other application functionalities.
* Performed Functional, Positive/Negative, UI, Boundary/Edge Case, Exploratory, Regression, and End-to-End Testing.
* Identified, documented, and tracked defects during test execution.
* Verified application behavior across different browsers and responsive layouts.
* Automated key test scenarios using Selenium WebDriver, Java, and TestNG.
* Implemented Page Object Model (POM) for reusable, maintainable, and scalable automation.
* Maintained test data and reusable components using Java, Excel, and Apache POI.
* Managed source code and automation project using Git and GitHub.

## Automation Framework
The automation framework is developed using Selenium WebDriver, Java, TestNG, Maven, and Page Object Model (POM).The Page Object Model approach is used to separate page elements and actions from test cases, improving code reusability, maintainability, and readability.

## End-to-End Workflow
Application Launch → Navigation → Examples of Bugs → Types of Bugs → Find Bugs → Product Selection → Cart → Bug Reporting → Validation.
